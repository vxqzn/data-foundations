# data-foundations

Core portfolio repository demonstrating software engineering and dimensional database modeling.

## English

### Project Structure
* [python/macro-tracker](python/macro-tracker): Terminal application tracking calorie and macronutrient targets. Features strict OOP validation, Mifflin-St Jeor TDEE calculations, and a 20-case Pytest suite.
* [sql/insse-analytics](sql/insse-analytics): PostgreSQL database warehouse modeling Romanian county economic turnover data. Features multi-level CTEs, window functions for YoY growth, and composite index optimization verified via EXPLAIN ANALYZE.

### Technical Stack
* Languages: Python, SQL
* Database: PostgreSQL
* Developer Tools: Pytest, Git, CLI

## Romana

### Structura Proiectului
* [python/macro-tracker](python/macro-tracker): Aplicatie CLI pentru monitorizarea caloriilor si macronutrientilor. Include validare OOP stricta, calcule Mifflin-St Jeor pentru TDEE si o suita de 20 de teste Pytest.
* [sql/insse-analytics](sql/insse-analytics): Depozit de date PostgreSQL pentru analiza cifrei de afaceri a judetelor din Romania. Include CTE-uri complexe, functii fereastra pentru calculul cresterii YoY si optimizare prin indecsi compusi verificati prin EXPLAIN ANALYZE.

### Tehnologii Utilizate
* Limbaje: Python, SQL
* Baze de date: PostgreSQL
* Instrumente: Pytest, Git, CLI
